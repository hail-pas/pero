# 注册与邀请接入

## 入口与职责

- 平台用户从 `/sso/register` 进入，使用平台注册策略。应用通过 `GET /oauth2/authorize` 提交 `prompt=create`，使用目标应用的注册策略。`create` 单独使用。有效的应用授权也可从登录页进入同一应用的注册流程。
- 超级管理员可在控制台的「新建用户」或「注册策略与邀请」选择「手动分享开户链接」或「手动分享链接（指定邮箱）」，核验受邀人身份后私下发送激活链接。只有指定邮箱的链接需要填邀请邮箱，受邀人可在个人中心另行验证该邮箱。超级管理员也可在「最近申请与邀请」为仍有效的邀请重新签发链接，旧链接随即失效，原到期时间不变。
- 超级管理员也可在已启用且支持个人空间的应用详情点击「邀请开户」。受邀人设置用户名和密码后即可开户。选填邮箱或手机号时，系统会发送验证码，受邀人可在个人中心验证并绑定。应用详情签发的邀请会在开户成功时同时授予该应用的访问资格。有效策略限制邮箱域名时，签发开户链接须勾选域名例外并填写理由。组织专用应用的新用户由组织管理员邀请加入组织。
- 自助注册支持邮箱、E.164 格式手机号和已开放注册的第三方身份源。邮箱和手机号分别通过邮件和短信验证，第三方自助注册仍需在 Pero 验证邮箱。限制邮箱域名时仅开放能验证邮箱的途径。组织专用应用不开放个人自助注册。渠道配置见 [应用接入与运维](application-portal-and-delivery.md#smtp-与短信)。
- 已登录用户可在 `/account/applications` 或 OAuth 权限恢复页申请普通应用访问资格。配置邮箱域名限制时，必须使用域名匹配的已验证邮箱。提交时自动校验，通过后由审批开关决定立即开通还是进入待审队列。管理员批准时再次校验邮箱。平台紧急停止会暂停所有应用的自助访问。已有账号收到应用邀请时，由管理员在成员页直接授予。已停用的资格须由有权管理员恢复。
- 组织 Owner 或 Admin 按角色权限发送邮件邀请。新用户可凭邀请创建账户和个人空间并加入组织。既有用户须登录与受邀邮箱匹配的账号，并完成适用的 MFA 或近期认证。接受时重新核对组织状态、成员上限和邀请人权限。应用访问资格仍由授权流程检查。平台全局紧急停止会阻止完成注册和接受组织邀请。

## 应用配置和回调

应用发起注册或组织邀请前，为 OAuth 客户端配置 `login_uri`，指向应用自身的 HTTPS 登录入口，例如 `https://app.example.com/login`。登记地址不能包含查询参数或 URL 片段。`redirect_uri` 负责接收 OAuth 授权结果，`login_uri` 负责发起新的授权请求。

| 场景 | 回跳方式 |
| --- | --- |
| 同一浏览器完成应用注册，原授权仍有效且可以绑定当前会话 | 建立或复用 SSO 会话，继续原授权请求及其 `state`、`nonce` 和 PKCE 参数。 |
| 首次提交联系方式前原授权已过期 | 返回可用的 `login_uri`，携带 `enrollment_status=expired`，由用户选择重新发起。 |
| 注册已完成，原授权过期或换设备办理 | 通过可用的 `login_uri` 发起新授权。 |
| 接受应用发出的组织邀请 | 返回来源客户端的 `login_uri`，携带目标 `tenant_id`。 |
| 用户取消应用注册 | 原授权可取消时，返回已校验的 `redirect_uri`，携带 `error=access_denied` 和原 `state`。其余情况通过可用的 `login_uri` 返回 `enrollment_status=cancelled`。 |

应用的登录入口应接受可选的 `tenant_id`，并识别 `enrollment_status=cancelled` 与 `enrollment_status=expired`。用户重新发起时，生成新的 `state`、`nonce` 和 PKCE 参数，并验证回调及签发的令牌。入口中的 `tenant_id` 只用于申请目标空间，登录上下文以已验证的令牌为准。没有应用来源或来源客户端不可用时，完成办理后回到 Pero 账户门户。[业务应用示例](../examples/tenant-app/README.md)

## 申请期限和进度恢复

- 自助注册申请有效期 24 小时，平台或应用开户邀请为 72 小时，组织邀请为 7 天。应用访问待审申请在撤回、审核决定或资格条件失效时结案。OAuth 授权请求默认有效 600 秒，授权码默认有效 120 秒。已创建的有效申请可以在原 OAuth 请求过期后继续办理。
- 申请进度可在原浏览器中继续查看。重发和审批通知可轮换办理链接，原申请到期时间保持不变。实际验证与完成需要有效的办理凭据以及适用的账号认证。换设备后使用最新收到的通知链接。
- “退出本次注册流程”结束当前浏览器流程。撤回申请会终止该申请并取消尚未投递的通知。已结束的申请和邀请可查看结果。

## 安全与失败处理

邀请和验证令牌以哈希形式保存，浏览器使用 HttpOnly Cookie 保持办理上下文。直接恢复应用注册的原授权时会核对授权请求和浏览器 nonce。新账号、身份及相应应用资格或组织成员关系与申请消费在同一事务内提交。若提交后建立登录会话失败，使用已创建的账号重新登录。应用仍需通过 OAuth 授权和回调取得令牌，并处理用户取消、授权过期及无应用访问资格的结果。
